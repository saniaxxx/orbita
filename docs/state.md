# orbita — состояние на 03.11.2026

Это снимок для агента, который только что забрал репозиторий. Он отвечает на
три вопроса: что уже работает, что сломано/не сделано и с чего продолжать.
Детали и замеры — в `docs/spec.md`; проверка — в `docs/agent-verification.md`.

## 1. Что это за проект

Конечная цель — автономный домашний агент, аналог Джарвиса: задачи, память,
профили, политики и управление домом. Алиса, Telegram, веб, CLI и внешние
MCP-клиенты — равноправные интерфейсы; голосовой стек — только канал общения.
Дом: Wiren Board (свет, розетки, климат, увлажнители, котёл), камеры, домофон,
электрозамки. Опасные действия — с подтверждением, fail-safe и аудитом.

Сейчас орбита — это ещё не агент, а работающий голосовой стек и фундамент для
него. Ниже — что уже есть, а что только предстоит.

Домашний голосовой стек для Яндекс Станции Лайт 1: эмуляция облака Яндекса,
потоковое распознавание, синтез, локальная LLM, веб-панель и каркас агента.
Без Docker для собственных сервисов, через systemd в LXC на Proxmox.

Код — один Rust workspace. Сабмодулей и Python-сервисов в репозитории больше
нет: protobuf-схемы, шаблоны промптов и конфиг прокси вендорены. Внешними
остаются llama.cpp, nginx, SearXNG и ffmpeg.

## 5. Что делать дальше

### 5.1. Glagol-спайк (следующий шаг для музыки)

1. Задать постоянный `GLAGOL_JWT_KEY` в юните Rust-quasar и перезапустить.
2. На машине в L2-сети станции:
   `cargo run -p orbita-glagol -- discover`.
3. `token`, затем `state`; в логе quasar должен быть `check_token`.
4. Негативный тест с токеном от quasar с другим ключом.
5. `play-url` на локальный MP3/FLAC; проверить `pause`, `resume`, `volume`.
6. Только после этого — Music Assistant.

Подробно — `docs/glagol.md`.

### 5.2. Музыка

- Music Assistant 2.10+ как внешний сервис: провайдер Yandex Station (локальный
  Glagol) + источник.
- Отдельный LXC `orbita-music`; Docker допустим для внешних сервисов,
  `network_mode: host` из-за mDNS/потока.
- Первый источник — локальная библиотека (известный `Content-Length`), затем
  Яндекс Музыка.
- Интеграция — Rust `orbita-mcp-music`; после голосового запроса музыка
  продолжается.
- `glagol/device_list` в quasar пока не реализован; проверить, нужен ли он MA.
- Multiroom — позже, но `target player_id` и маппинг `duid ↔ player` заложить
  сразу.

### 5.3. Агент

Первая версия `orbita-agent` есть: `/process` вместо processor, SQLite-сессии,
напоминания без LLM, push через quasar, директивы станции и MCP-поиск.
MCP-версия развёрнута в CT 101 04.11.2026: real-тест 5/5, живой WS-запрос
«какая сейчас погода в Москве» прошёл через SearXNG и вернул погоду. Голосом
на станции поиск ещё не проверен. Порядок замены processor и проверки —
`docs/agent.md`. Дальше: MCP-инструменты дома, политика grant/nonce,
`orbita-home`, затем Telegram.

### 5.4. Инструменты процессора

- Сейчас все функции всех MCP-серверов уходят в промпт, классификатора нет;
  `NLP_SERVICE_URL` — заглушка.
- План: метрики и golden set → починить `McpFunctionServer` (кэш `tools/list`,
  reinit на 404, таймауты) → overlay с группами/allowlist и компактным
  рендером → fast path → rule-router → constrained decoding.

### 5.5. GPU и Strata

- Сначала одна A2 16 ГБ: Strata + TTS + GigaAM, резерв 2048 МиБ, LLM ~14 ГБ.
- Позже, если есть слот/обдув/БП — T400 под STT/TTS, A2 целиком под LLM.
- Strata — только после POC: поддерживаемые модели, JSON не грамматический,
  VRAM-лимиты. llama.cpp остаётся fallback.

### 5.6. Дом

- `orbita-home`: Wiren Board по MQTT — свет, розетки, климат, увлажнители,
  котёл, датчики, сцены, электрозамки, калитка и ворота.
- Безопасность исполнительных устройств (импульс, interlock, автозакрытие)
  живёт в `wb-rules`, а не в агенте: при падении агента дом продолжает работать.
- Камеры — через локальный Frigate: подписка на `frigate/reviews`, снимки
  байтами, persistent MQTT, catch-up через API; видео агент не хранит.
- Телевизоры — Android TV через Google TV Remote protocol v2 (pairing/TLS);
  ADB не используем. Bosch/Liebherr — официальные API, read-only и в конце.
- Домофон — SIP/ONVIF/API, отдельная интеграция, позже.
- Начинать с безопасного: свет, розетки, датчики. Telegram как второй канал —
  до замков, иначе подтверждать нечем. Котёл, замки, калитка, ворота — только
  после политики подтверждений, fail-safe и аудита.
- Голос не является аутентификацией; для опасных действий нужно явное
  подтверждение/PIN вторым каналом.

## 6. Известные пробелы

- Дверной замок **не на реле света** (прямое уточнение владельца 04.11.2026);
  точное место неизвестно, к `orbita-home` не подключён и голосовое
  управление светом не блокирует. `wb-mr6cu_54` — не замок: K4 — клапан
  увлажнителя, остальные каналы не используются.
- `orbita-quasar`: голосовой ввод, sync/glagol device_list, постоянная сессия
  процессора; разбиение ответа на фразы отключено (D-11). 04.11.2026 проверено:
  если `Close` отправлять только у последнего `TtsSpeak`, станция играет все
  потоки, но по задержке разбиение невыгодно (первый chunk ~0,95 с, три chunk'а
  ~2,1 с против ~0,93 с одним потоком), поэтому toggle не добавляем.
- `orbita-processor`: нет NLP, потокового разбора function_calls, JSON-schema
  валидации аргументов.
- TTS: в проде Vosk; модель на CUDA считается за 75–104 мс, но HTTP-ответ
  занимает 1,2–1,4 с — почти всё съедает ffmpeg на каждый запрос. Оптимизация
  следующего шага: кодирование Opus без внешнего процесса.
- Музыки нет; Glagol-спайк не проверен на станции.
- Android TV: TCL Smart TV Pro «Гостиная» (`192.168.250.109`) спарен;
  написан `orbita-tv` (MCP, порт 8898), проверены `state`, громкость и
  Wake-on-LAN на живом TV; в агент и на стенд ещё не развёрнут. WoL работает
  при «Оптимизированном потреблении» (сеть в ждущем режиме). Sber `TV-4JR` (`192.168.250.111`) в standby, Remote v2
  закрыт — доступны Cast/AirPlay, полноценный пульт под вопросом.
- `orbita-glagol` не умеет переподключаться, очередь и подписку на события.
- `orbita-agent`: MCP-поиск работает на стенде, но голосом на станции ещё не
  проверен; дома, профилей и voice ID нет. Штатные директивы станции работают
  (D-15), напоминания понимают словесные числа. Голосовой харнесс
  `deploy/verify/` проходит 13/13.
  `orbita-home` — модель и safe-write, без `wb-rules`, Frigate, Android TV,
  Bosch/Liebherr, домофона и замков.

```sh
git pull --ff-only
cargo fmt --all --check
cargo clippy --workspace --all-targets -- -D warnings

```

Python-сервисами; их роль выполняют интеграционные тесты в `crates/*/tests`.
