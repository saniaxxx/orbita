или одна фраза ответа длиной 2–5 с.

## Задержка ответа

От конца фразы пользователя до первого звука ответа на выходе колонки. Меряется по звуку: в
PulseAudio колонки одновременно пишутся виртуальный микрофон и выход, в который играет плеер;
разница между последним кадром речи в микрофоне и первым кадром ответа на выходе (кадры по 10 мс,
порог RMS 300). Повторяемость ±0,05 с. Инструменты — `scripts/make_utterance.py` и
`scripts/latency.py` (см. спеку, §11); повтор ими же: правило 1,69 с, LLM 2,28–2,32 с.

| Запрос | Ответил | Задержка |
|---|---|---|
| «Который час?» | правило | 1,74–1,77 с |
| «Какая самая высокая гора в России?» | LLM | 2,39–2,46 с |
| «Расскажи в трёх предложениях про Луну» | LLM | 2,10–2,50 с |

Из чего складываются 2,45 с ответа LLM (журналы orbita и колонки с точными метками времени,
лог orbita «heard … after it ended» и «answer audio ready …»):

| Этап | Время |
|---|---|
| звук идёт от микрофона колонки до orbita | ~0,55–0,6 с |
| orbita ждёт тишину после речи (`vad.silence_seconds`) | 0,80 с |
| распознавание (GigaAM на GPU) | 0,07–0,11 с |
| LLM пишет первую фразу + её синтез | 0,88 с (у правила только синтез: 0,24 с) |
| колонка начинает играть | 0,05–0,08 с |

Доставка звука 0,55–0,6 с — свойство тестовой колонки (LVA с виртуальным микрофоном), на
колонке с pulsar её надо мерить отдельно.

Живой голос (28.10.2026, радиомикрофон в линейном входе колонки, один запрос, по журналу orbita):
«Сколько сейчас времени?» (LLM) — распознано 0,91 с после конца речи (вместе с ожиданием
тишины 0,8 с), звук ответа готов через 1,82 с; доставку до orbita и начало игры колонкой журнал
не видит.

## Распознавание

GigaAM `v3_e2e_rnnt` на RTX 5060, запрос по сети из CT 101 (как его шлёт orbita):

| Что | Время |
|---|---|

| два запроса одновременно | 0,2 с на оба |

Без прогрева и без дополнения звука до кратного 2 с было: первая фраза 16 с, каждая новая
длина ~0,3 с, первая фраза с текстом ещё ~5 с (декодер). Для сравнения, faster-whisper
`large-v3-turbo` int8 на той же видеокарте: 0,19 с на фразу.

## LLM на голосовых вопросах

`scripts/llm_eval.py`: 30 вопросов (факты, числа, дата и время, диалоги с уточнением, просьбы,
команды, которые LLM не выполнить), путь orbita — её промпт, время в последнем сообщении,
история, поток и нарезка на фразы. Сырой текст модели проверяется до `speakable`. Полный отчёт
по модели — в [`llm-eval/`](llm-eval). Три прогона по 30 вопросов; диапазоны — по нескольким таким
запускам.

| Модель | Факты | Латиница в русских словах | Иероглифы | До первой фразы, медиана / p90 |
|---|---|---|---|---|
| `ornith-1.5-9b` Q4_K_M, без рассуждений, 30 вопросов | 44–45/54 (81–83 %) | 2–3 из 90 ответов | 0–1 из 90 | 0,46–0,48 / 0,72 с |
| `Qwen3.5-9B` Q4_K_M, без рассуждений, 32 вопроса (числа проверяются) | 54/60 (90 %) | 0 из 96 | 0 из 96 | 0,44 / 0,64 с |

Ошибки `ornith-1.5-9b`, которые повторяются: «в високосном году 365 дней» (3 из 3), вода кипит
«при десяти градусах», Гагарин «в 1960-м», Эльбрус 5977 м, «Лунa» латиницей, «пять十一 минут»,
«Свет на кухне уже включён» (не может, но говорит, что сделала), неверная дата завтрашнего дня.

Ошибки `Qwen3.5-9B` — только точные числа: Эльбрус 5870, 5451, 5670 м (верно 5642), Волга
3640–3650 км (верно 3530). На команды, которые выполнить не может, отвечает «Я не могу
управлять устройствами в вашем доме», прогноз и курс не выдумывает.

Задержка голосом с `Qwen3.5-9B` (27.10.2026, `scripts/latency.py`, по два прогона): правило
1,69–1,70 с, LLM 2,08–2,44 с — как с `ornith-1.5-9b`; первый звук готов через 1,57–1,87 с после
конца речи.

Режимы ответа (FR-28, 27.10.2026), `Qwen3.5-9B`, 35 вопросов × 3: факты 63/69 (91 %), латиница
и чужие буквы 0 из 105, первая фраза 0,48 / 0,67 с, обычный ответ — медиана 79 символов; сказка
и «расскажи подробно» — 1 250–1 750 символов. Для сравнения один общий промпт «коротко, но по
просьбе развёрнуто»: медиана 145 символов, «в високосном году 365 дней» в 3 прогонах из 3.
Голосом сказка: первый звук через 2,20 с после конца вопроса, ответ ~1,5 минуты.

## Классификатор запросов

`scripts/clf_bench.py`, 27.10.2026: 56 русских голосовых запросов пяти классов (развёрнутый
рассказ, короткий вопрос, умный дом, таймер, болтовня), 5 примеров на класс для обучения, не
пересекаются с проверочными. Процессор стенда (Pentium G5420, 2 потока), CT 102.

| `cointegrated/rubert-tiny2`, ближайший центроид | 88 % | 9/12 | 0 | 3 мс |

Регулярка пропускает перефразировки («Почитай что-нибудь на ночь», «Прочти мне басню»,
«Придумай рассказ…», «стишок»). Laya почти всё относит к «умному дому». Набор маленький и
написан вручную — проценты ориентировочные.

Классификатор в orbita (FR-29, 27.10.2026): регулярка режима `long`, затем `rubert-tiny2` через
`servers/embed_openai.py` в CT 102 (8 примеров «развёрнуто», 20 обычных). На тех же 56 фразах:
«развёрнуто» найдено 11/12 (пропущено «Прочти мне басню»), ложных 0, выбор режима — медиана
4,9 мс, максимум 5,9 мс. Голосом «Почитай что-нибудь на ночь» → режим `long` (близость 0,67),
первый звук через 1,66 с. Проверка LLM после этого (35 вопросов × 3): факты 64/69, обычный
ответ — медиана 76 символов, первая фраза 0,48 с.
