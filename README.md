# orbita

Домашний стек для Яндекс Станции: эмуляция облака Яндекса, потоковое
распознавание, синтез, локальная LLM, веб-панель и ядро домашнего агента.
Без докера, через systemd в LXC на Proxmox.

## Что строим

Конечная цель — не голосовой помощник, а **автономный домашний агент**,
аналог Джарвиса: он ведёт задачи и расписание, помнит предпочтения, следит за
домом и управляет им. Алиса и станция — только один из интерфейсов общения,
наравне с Telegram, вебом, CLI и внешними MCP-клиентами. Голосовой стек
(quasar, ASR, TTS, processor) — канал, а не центр системы.

Ядро — `orbita-agent`: планировщик, задачи, память, профили, политики, аудит и
MCP-инструменты. Дом подключается через Wiren Board по MQTT: свет, розетки,
климат, увлажнители, котёл, датчики и сценарии; отдельными интеграциями —
камеры, домофон и электрозамки. Опасные действия (замки, котёл, охрана)
требуют подтверждения, имеют fail-safe и аудит; голос не является
аутентификацией.

Код — **один Rust workspace** в этом репозитории, без сабмодулей и сторонних
исходников. Всё, что нужно для сборки (protobuf-схемы, шаблоны промптов, конфиг
прокси), лежит в `deploy/` и `crates/`. Внешними остаются только исполняемые
сервисы: llama.cpp, nginx, SearXNG и ffmpeg.

| Крейт | Роль |
|---|---|
| `orbita-core` | конфиг из env, логи, общие ошибки |
| `orbita-proto` | prost-типы AAPI из вендоренных `.proto` |
| `orbita-quasar` | облако для станции: sync, OAuth, директивы, HTTP-роутеры |
| `orbita-processor` | «мозг»: LLM, JSON-ответы, функции, MCP |
| `orbita-mcp-search` | MCP-мост к SearXNG |
| `orbita-tts` | синтез: Vosk TTS ru 0.10 на `ort`, в проде на 9170 (CT 100) |
| `orbita-asr` | потоковое распознавание (VAD/WS; GigaAM v3 на `ort`, CPU и CUDA проверены) |
| `orbita-station-sim` | симулятор станции: текст, голос, replay |
| `orbita-dashboard` | веб-панель пайплайна и метрик |
| `orbita-cli` | прогрев процессора и замер задержек |
| `orbita-glagol` | спайк локального Glagol: mDNS, токен, команды станции |
| `orbita-home` | Wiren Board MQTT: модель устройств, safe-write, stale, grants |
| `orbita-agent` | ядро голосового канала: `/process`, директивы станции, SQLite, напоминания, LLM |

## Структура

```
crates/          Rust workspace: сервисы и библиотеки
deploy/
  systemd/       unit-файлы и drop-in'ы
  install/       скрипты установки для внешних сервисов и станции
  proxy/         вендоренный конфиг https-proxy (nginx + генератор сертификатов)
  processor/     наши шаблоны промптов (system/functions/state)
  home/          пример конфига orbita-home
  searxng/       настройки внешнего SearXNG
  station/       hosts станции с доменами Яндекса
  llama-json.gbnf  грамматика JSON для llama.cpp
docs/
  state.md              текущее состояние стенда и что делать дальше
  spec.md               спецификация (SDD, замеры в §11)
  features.md           бэклог фич и идей
  agent-deploy.md       задание агенту-развёртывателю
  agent-verification.md туториал для агента-проверяющего
  agent.md              голосовой агент: директивы станции, запуск, замена processor
  dashboard.md          запуск и API веб-панели
  glagol.md             спайк локального Glagol для музыки
```

Сборка и запуск:

```sh
cargo build --release -p orbita-processor -p orbita-mcp-search -p orbita-dashboard -p orbita-cli
cargo test --workspace
```

Обновление — обычный `git pull`; сабмодулей нет.

## Правила работы

- Разработка идёт по SDD: изменение поведения и достигнутый результат фиксируются в
  `docs/spec.md` (цифры — в разделе «Замеры»), в том же коммите.
- Долгие операции (установка пакетов, перезапуски, цепочки `ssh` → `pct exec`) запускаются
  фоном, а не блокирующей командой: длинная цепочка выглядит как зависание и её прерывают.

## Лицензия

Собственный код этого репозитория — MIT, кроме портов чужого кода:
`crates/orbita-quasar`, `crates/orbita-processor`, `crates/orbita-station-sim`,
`crates/orbita-proto` — GPL-3.0, `crates/orbita-asr` — MPL-2.0.
Вендоренные protobuf-схемы (`crates/orbita-proto/protos`) взяты из
`v3rt3p/quasar-protos` и остаются под лицензией их авторов.
