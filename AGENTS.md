# orbita — правила для агентов

- Сначала прочитать `docs/state.md` (текущее состояние), `docs/spec.md`
  (целевая архитектура) и `docs/plan.md`.
- Одна ветка — `main` (решение пользователя 08.11.2026: ветки OpenClaw, ASR и
  home-MCP влиты). Короткие ветки/worktree — только на время задачи, затем в
  `main`; push — только по решению пользователя.
- С этой машины нет доступа к стенду: не выполнять `ssh`/`pct` и не перезапускать
  удалённые сервисы. Готовить команды для человека.
- Перед выводом «готово» прогнать офлайн-ворота:
  `cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings`
  и `cargo test --workspace`.
- Старые спеки и замеры доступны в git-истории; в `docs/` только актуальные
  `spec.md`, `plan.md`, `state.md`, `README.md`.
- Не коммитить секреты, записи голоса и приватные запросы.
- Не выдавать L0–L2 за проверку на реальной станции; указывать уровень проверки.
- Не подгонять тесты под неверное поведение: эталон — текущий рабочий стек и spec.
