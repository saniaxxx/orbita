# orbita — правила для агентов

- Сначала прочитать `docs/state.md` (текущее состояние), `docs/spec.md` и
  `docs/agent-verification.md`.
- Работать в единственной ветке `main`; других веток в репозитории нет.
- С этой машины нет доступа к стенду: не выполнять `ssh`/`pct` и не перезапускать
  удалённые сервисы. Готовить команды для человека.
- Перед выводом «готово» прогнать офлайн-ворота из `docs/agent-verification.md`:
  fmt, clippy и `cargo test --workspace`.
- Не коммитить секреты, записи голоса и приватные запросы.
- Не выдавать L0–L2 за проверку на реальной станции; указывать уровень проверки.
- Не подгонять тесты под неверное поведение: эталон — текущий рабочий стек и spec.
